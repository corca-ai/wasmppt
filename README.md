# wasmppt

A loss-aware Rust/WebAssembly engine for generating and rendering PowerPoint Open XML
packages in browsers, Cloudflare Workers, and native applications. Compile a template once,
reuse it for repeated generation, and preserve unknown content outside edited parts.

Pre-alpha: APIs are unstable and crates/npm packages are unpublished. The
[browser playground](https://corca-ai.github.io/wasmppt/) runs bundled templates locally.
